## 🃏 POKER · SUGERENCIAS AL DEV (GEMINI)

Cada resultado de una partida PvP en `/poker` ahora trae un botón extra: **"Enviar sugerencias al dev"**.

### 🔁 Flujo

1. Termina la mano → el embed de resultado (`Ganador: @x` / `Empate`) se reescribe con texto más claro y gana un botón.
2. Quien lo pulsa debe ser el retador original o estar en `OWNER_IDS` — cualquier otro recibe un ephemeral de "No autorizado".
3. El embed se manda por **DM** al dev (`DEV_USER_ID` o el primer `OWNER_IDS`), con un botón **"Generar sugerencias (Gemini)"**.
4. Solo el dev puede pulsarlo: dispara `generateBroadcastWithGemini()` con el título/descripción actual como digest y pide un título + descripción mejorados en JSON.
5. La sugerencia vuelve en un embed morado con botón **"Aplicar mejoras"**.
6. Al aplicar, se edita el mensaje original en el canal del servidor (no la DM) con el nuevo título/descripción y se cierran los collectors.

### ⏱️ Ventanas de los collectors

| Collector | Duración |
| --- | --- |
| Botón "Enviar sugerencias" (en el mensaje del resultado) | 5 min |
| Botón "Generar sugerencias" (en la DM) | 15 min |
| Botón "Aplicar mejoras" (en la DM) | 10 min |

### ⚠️ Nota de seguridad

- La autorización para *enviar* la sugerencia se valida (`interaction.user.id` o `ownerUserIds()`), pero cualquier canal donde se juegue `/poker` puede terminar disparando una llamada a Gemini y una edición de mensaje si el dev lo permite.
- Recomiendo registrar este flujo en `bot_logs` para mayor trazabilidad.

## 🚀 MONITOR DE ARRANQUE / REINICIO

`bot/events/ready.ts` ahora publica un embed de salud del sistema cada vez que el bot entra en línea (arranque o reinicio), en el canal:

- **Canal:** `1530019095565570158` (`STARTUP_STATS_CHANNEL`)

### 📊 Contenido del embed

| Campo | Fuente |
| --- | --- |
| Versión | `BOT_VERSION` |
| Entorno | `process.env.NODE_ENV` |
| PID | `process.pid` |
| Uptime | `process.uptime()` formateado `Xh Ym Zs` |
| Comandos registrados | `client.commands.size` |
| Servidores | `client.guilds.cache.size` |
| Usuarios cacheados | suma de `memberCount` |
| Canales cacheados | `client.channels.cache.size` |
| Gateway ping | `client.ws.ping` |
| Memoria RSS / Heap usado-total / External | `process.memoryUsage()` |

### 🎨 Estilo

El embed viene con `author`, `thumbnail`, emojis por campo, valores en negrita, y una descripción narrativa: "Zero Two ha vuelto a entrar en línea…".

### ⚠️ Nota de seguridad

- El embed expone **PID, RSS/heap real y conteo de servidores/usuarios**, por lo que el canal debe ser un espacio restringido para staff.
- Es recomendable mover `STARTUP_STATS_CHANNEL` a una variable de entorno y validar permisos de canal en runtime.
