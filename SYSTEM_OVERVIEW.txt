🎯 CÓMO FUNCIONA:

  1. Usuario intenta acceder a feature beta
                    ↓
  2. Sistema verifica BETATESTERS_IDS
                    ↓
  3. ¿Es beta tester?
       │─ Sí ──→ Acceso permitido + features habilitadas
       │
       └─ No ──→ Acceso denegado + mensaje


⚙️ CONFIGURACIÓN REQUERIDA:

  En tu archivo .env:
  
  BETATESTERS_IDS=123456789,987654321,555555555
  
  Reemplaza los números con los Discord User IDs de tus beta testers.

🚀 ENDPOINTS DE LA API:

  Públicos (requieren sesión):
  └─ GET /api/beta/status

  Protegidos (requieren ser beta tester):
  ├─ GET  /api/beta/features
  ├─ GET  /api/beta/panel
  └─ POST /api/beta/feedback

  Admin (requieren ser owner):
  ├─ POST /api/beta/manage
  └─ GET  /api/beta/info


💬 COMANDOS DE DISCORD:

  /beta info          → Información del programa
  /beta features      → Ver features en beta
  /beta feedback      → Enviar feedback
  /beta manage add    → Añadir beta tester (owner)
  /beta manage remove → Remover beta tester (owner)
  /beta manage list   → Listar beta testers (owner)


📝 EJEMPLO DE USO:

  # Backend - Proteger ruta:
  import { requireBetaTester } from "../middleware/betatesters";
  
  router.get("/experimental", requireBetaTester, (req, res) => {
    res.json({ data: "Feature experimental" });
  });

  # Frontend - Usar hook:
  import { useBetaTesterStatus } from "../lib/useBetaTester";
  
  const { data: status } = useBetaTesterStatus();
  if (status?.isBetaTester) {
    // Mostrar feature beta
  }

  # Discord - Comando:
  /beta features
  → Muestra features en beta disponibles (solo si eres beta tester)
